# Changelog

## 2026-05-23

- blueprint catalogue: added 4 new ships (Wraith/scout, Sting/interceptor, Talon/fighter, Maul/bomber) as siblings of Tellus under `bp-mod-engineering`. Each ship is generated by a new `buildShipFamily` helper that expands to the ship blueprint + 5 MK1 addons (engine/deflector/plating/stabilizer/weapons), namespaced by `targetId` so each ship has its own upgrades
- ResearchTree: progressive reveal — `buildLayout(researchedBlueprints)` runs dynamically and only includes a node's children if the node itself is researched (root nodes are always included). Hidden subtrees take up no layout space, so the visible tree packs into the tightest left-to-right form. Ship bbox uses `CARD_FRAME` dimensions until researched, then switches to `SHIP_FRAME` to accommodate the Upgrades sub-frame
- ShipGroupNode: addons grid switched from 3×2 to 5×1 single-row layout; `SHIP_FRAME_WIDTH` grew to 512 but `SHIP_FRAME_HEIGHT` shrank to match `CARD_FRAME_HEIGHT` so a ship's bbox is no taller than a regular module card. Upgrades only render once the ship is researched
- ResearchTree: click-to-research is wired via ReactFlow's official `onNodeClick(event, node)` callback (cleaner than fighting per-card pointer events). Addons inside `ShipGroupNode` keep their own `onClick` with `stopPropagation` so the click registers as the specific addon rather than bubbling up to the ship node. `isPending` guard on the mutation prevents duplicate-fire double-click races
- ResearchCard: non-researched cards get a 45° zebra-stripe overlay (`repeating-linear-gradient`) plus a dimmed thumbnail behind it. Image renders behind the stripes (position: absolute); status corner stays on top. Stripes hide when the card transitions to researched
- ResearchTree: camera animation on each research now zooms OUT from the freshly researched item. Implementation: diff old/new `researchedBlueprints` to find the newly researched id, pre-shift the viewport via `setViewport(..., { duration: 0 })` to compensate for the node's world-position change (since the layout re-centers the parent within its grown subtree), then `setCenter(newlyResearchedCenter, fitZoom, duration: 600)` to animate outward to the new fit. Double-rAF ensures ReactFlow's internal node store has committed before the camera math runs
- ResearchTree: mock backend `/research/start` simplified to instant-complete (no `researchInProgress` timer, no research-module-operational gate) so the tree can be iterated without first building the section in StationGrid. Error responses now include the failing reason (`Already researched`, `Insufficient materials: iron (have 5, need 15)`, etc.) and the api wrapper surfaces the status text in the thrown Error message. `useStartResearch.onSuccess` writes the response directly into the cache via `setQueryData` (then invalidates) for an immediate UI update
- ResearchTree: pan + zoom interactions enabled. Mouse wheel zooms (`zoomOnScroll`, `preventScrolling: true` so the page doesn't scroll while the cursor is over the canvas), drag pans. Pan is bounded by a soft `onMoveEnd` constraint — on drag/zoom release, if the viewport center has moved outside the layout bbox, `setCenter(clampedCenter, ..., duration: 200)` smoothly animates the camera back to a valid position. `translateExtent` is deliberately NOT used because it's in world coords and snap-to-centers when smaller than the viewport
- BlueprintBackground: tuned coarse/medium/fine palette to `#111C24` / `#0D151C` / `#091016` on `#070d14` base (compressed dark hierarchy)

## 2026-05-21

- BlueprintBackground: tuned the grid hierarchy to a three-tier CSS gradient stack — coarse 144px continuous lines (`#111C24`, 1.5px), medium 36px sub-grid that divides each coarse cell into a 4×4 (`#0D151C`, 1px), fine 18px sub-grid that splits each medium cell into a 2×2 (`#091016`, 1px). 144 is intentional (not 140) so MEDIUM=36 and FINE=18 stay integer and don't antialias-thicken on `.5` pixel positions. All solid; removed intersection dots/crosses and inner-dash experiments
- BlueprintBackground: dropped the `intersectionColor` prop entirely; removed the radial-gradient dot layer, SVG cross layer, and the `crossIntersectionLayer` / `dashedGridLayer` helpers and their associated background-position offset. Public API is now just `baseColor` / `coarseLineColor` / `mediumLineColor` / `fineLineColor` (+ `sx` passthrough)
- NodeFrame: inner box now fills the available frame area via `left: 0, right: 0, bottom: 0` (previously shrank to content), so `alignItems: center, justifyContent: center` actually centers children inside the frame — fixes ReactFlow edge endpoints landing in empty space when the child is smaller than the frame
- ShipGroupNode: split into two sibling `NodeFrame`s inside one ReactFlow node — small Tellus frame on the left (label = ship.name, `CARD_FRAME_HEIGHT` / `CARD_FRAME_WIDTH` — same size as engineering/research/etc.) and a wider Upgrades frame on the right (label "Upgrades", contains the 3×2 addon grid). Flex row vertically centers the small Tellus frame against the taller Upgrades frame so the target handle at `getBoxCenterY(SHIP_FRAME_HEIGHT) = 100` still lines up with the Tellus card midline
- ShipGroupNode: `BOX_GAP = 4`px between the Tellus and Upgrades frames; addon grid no longer has a redundant `p: 1` (the NodeFrame already centers content with `FRAME_PADDING` worth of breathing room). `SHIP_FRAME_WIDTH: 408 → 372` and `SHIP_FRAME_HEIGHT: 230 → 184` so the node bbox snugly fits its content (`92 + 4 + 276 = 372` wide; `6 + 80 + 12 + 80 + 6 = 184` tall)
- docs/research-tree-pan-zoom.md — decision record covering ReactFlow vs custom pan/zoom vs `react-zoom-pan-pinch`. Captures what ReactFlow does/doesn't do for us, the three options with effort estimates, and the recommendation framework so we don't re-derive this next time
